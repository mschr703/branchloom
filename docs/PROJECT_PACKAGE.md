# Projektpaket: sichern und importieren

Über **Projekt sichern** im linken Workspace-Bereich wird das aktive Projekt als neue `.json`-Datei gespeichert. Die App überschreibt keine vorhandene Datei. Der Export enthält Spalten, Karten mit Beschreibungen, Prioritäten, Labels, Archivstatus und Abnahmekriterien, Memory-Notizen und die Struktur der Workflows. Er ist ein **Projektpaket**, keine vollständige Kopie der App-Datenbank.

Die Datei ist **unverschlüsselt** und kann persönliche Karten, Kriterien und Notizen enthalten. Bewahre sie entsprechend auf. Sie enthält keine Agentenprofile oder Zugangsdaten, keine Sitzungsprotokolle, keinen Queue-Fortschritt, keine Browserdaten, keine Trello-Importhistorie, keine Git-Worktrees, keine Kartenanhänge oder Dateiverweise, keine QA-Berichte oder Review-Kommentare und keine Dateien aus dem Projektordner. Der absolute Projektpfad wird nicht gespeichert.

Unter **Projektaktionen** sind die Wege direkt getrennt: **Codeordner hinzufügen** öffnet das Formular für Namen und absoluten Pfad eines vorhandenen Ordners. Branchloom verknüpft ihn, ohne Dateien zu kopieren. **Branchloom-Paket (.json) importieren** öffnet direkt den Dateidialog für eine Datei aus **Projekt sichern**. Anschließend zeigt die App vor dem Import Namen und Anzahl von Spalten, Karten, Notizen und Workflows. Gib einen neuen Projektnamen und einen bereits vorhandenen absoluten Ordner an. Ein bereits registrierter Ordner wird abgelehnt. Der Import ändert weder den Ordnerinhalt noch ein vorhandenes Projekt. Neue Exporte nutzen Formatversion 2 mit Abnahmekriterien; alte Version-1-Pakete bleiben lesbar. Ältere App-Versionen weisen Version 2 zurück, damit Kriterientexte nicht still verloren gehen. Unbekannte Versionen, ungültige Referenzen und Dateien über 8 MiB werden abgelehnt.

Der Import vergibt neue IDs. Abnahmekriterien bleiben in Reihenfolge erhalten, beginnen aber ohne Prüfverweise. Auch ältere Pakete ohne Kriterien lassen sich importieren. Alle Spalten starten ohne Agenten, Modell, Effort und Autostart. Alle importierten Workflows starten als Entwurf, mit Freigabe vor jedem Schritt. Die Warteschlange bleibt aus. Vor einem Agentenlauf musst du die Agentenzuordnung und Route neu prüfen. Archivierte Karten bleiben archiviert. Die App startet beim Import keinen Agenten.
