# Project conversation: first local slice

The project conversation is a read-only Codex CLI exchange over selected entries from Branchloom's local Memory index. It searches saved cards, completed agent transcripts, Git commits, and indexed code passages for the **active project only**. The model receives at most eight short excerpts with source IDs, dates, paths relative to the repository where available, the index timestamp, Git revision, and a partial-index warning. A task source also carries its current board column. Branchloom rejects common secrets and absolute user paths before handing context to the CLI.

The response must cite IDs from the supplied entries. A nonexistent ID is rejected. A response with no citations is replaced by an explicit inability to verify and cannot produce a suggestion. Citations establish which snippets the model used; they do **not** prove every sentence of the model's interpretation. Users can open cited cards or agent sessions, and the interface shows source dates and the index timestamp. Code and commit snippets are indexed from a Git revision, so working files may differ.

Open **Projektgespräch** in the project navigation. The UI holds the conversation and optional task or canvas outline locally in component state. The proposal can be edited. A separate **Karte bewusst erstellen** click creates a card in the project's To Do column and opens it on the Board. A canvas outline has no persistence path in this slice. No card, workflow, canvas node, file, or session is written by the discussion API. There is no cloud model fallback.

`ProjectChat` is mounted by the app with the current `ProjectSnapshot`, source navigation and the explicit To Do card action. `window.studio.discussProject` is exposed through preload and IPC. The project workflow agent setting must point to an enabled local Codex CLI installation.

This is a bounded word-search and excerpt workflow, not semantic retrieval or a persistent project-wide chat history. It does not index every source, infer truth from raw agent output, or guarantee that a cited sentence is correct. New turns are retained only while the view is mounted. A richer conversation with saved threads, source selection, canvas handoff, other safe agent adapters, cancellation, and a full visible Windows run remain open.
